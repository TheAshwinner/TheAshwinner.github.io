{%- comment -%} Renders site.data.links as a row of icons from icon.html. The label is kept in the DOM but visually hidden, so each link still has an accessible name - the icon itself stays aria-hidden. `title` gives sighted readers a tooltip, which matters most for the Scholar mark. Because the anchor has text content, that text wins the accessible name and the title is not announced twice. An entry with `email: true` becomes a mailto: built from site.email_address, so the address is never rendered as page text. {%- endcomment -%}
